# Gestor de Bancos

Gestor de Bancos es una aplicación móvil/web construida con Ionic + Angular (con soporte para Android vía Capacitor) pensada para administrar y dar seguimiento a la operación de una tienda/negocio que trabaja con agentes bancarios.

La app incluye un sistema de autenticación con control de acceso por roles (por ejemplo, admin y cajero), y organiza el flujo de trabajo en módulos como: Dashboard, Transacciones (listado, formulario y detalle), Bancos, Servicios, Comisiones, Caja, Corte y Usuarios, además de una pantalla para cambiar contraseña. Esto permite centralizar la captura y consulta de información operativa, así como la administración de catálogos y usuarios dentro del mismo sistema.
